# Sổ Chi Tiêu

Web app quản lý chi tiêu cá nhân, giao diện kiểu điện thoại. Mở link là dùng, không cần cài.

- Ghi chi / thu, tự xếp danh mục theo ghi chú
- Lịch chi tiêu tô màu theo mức chi
- Thống kê, điểm nổi bật, mục tiêu tiết kiệm có lịch sử góp
- Hoá đơn định kỳ, sao lưu / khôi phục bằng file

Dữ liệu chỉ lưu trong trình duyệt của máy đang dùng, không gửi lên đâu cả.
Trên iPhone/iPad: mở bằng Safari → Chia sẻ → **Thêm vào MH chính** để dùng như app.
